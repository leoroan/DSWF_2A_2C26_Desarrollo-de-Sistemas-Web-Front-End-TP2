# Dirección visual y estructura

Esta primera etapa conserva la funcionalidad de la base y define una presentación de estudio digital: sidebar tinta, superficies claras, violeta y pequeños acentos verdes. «Espacio de ideas» es una identidad provisional; debe adaptarse al equipo y al TP1.

## Dónde editar

- `src/index.css`: paleta, tipografía, foco y estilos globales.
- `src/components/layout/`: estructura compartida y navegación responsive.
- `src/components/common/Page.css`: encabezados, botones, formularios y superficies comunes.
- `src/components/team/`: presentación, ilustración CSS y tarjetas reutilizables.
- `src/pages/`: composición de cada pantalla.
- `src/data/`: información del equipo, navegación, recursos, árbol y bitácora.
- `src/services/`: consultas externas.
- `src/router/`: rutas de React Router.

Los nombres y las responsabilidades personales siguen pendientes. Los tres perfiles de la base no confirman la cantidad real de integrantes. La ilustración de portada está construida con CSS y no depende de imágenes externas.
